# Release 0.6.1 (2026-10-27 UTC)

All five npm packages are published at 0.6.1, and `latest` points to 0.6.1.
Tag `v0.6.1` is pushed at `418d82f89d1c887640ada72f384c1e7a6c89b667`, the
commit `release.yml` run 40464376486 checked out. The registry's SHA-512
integrity matches every tarball below.

This is a patch release under docs/release.md §3: everything in the
Unreleased section is compatible. The new `PostEffects` fields and `og.Wind`
are off by default, and `neutral` is appended to `toneMapping`. On top of
that come the Windows fixes: WebGL2 on ANGLE/D3D11, the 2D publish refusal's
paths, the debug og-gfx stack, and the web harness.

## Owed after 0.6.1

- **og-ui/glass on Windows WebGL2** (RMSE 0.01728): an ANGLE D3D11 bug.
  `textureSize` of a view whose base level is b answers with level 2b's
  size. The fix is `f102a6e3` on `webgl2-glass-pyramid-size`, which brings
  WebGL2 to 0.00035. It still needs the metal lane before it merges. The
  view glow chain (`bloom_chain`) probably has the same pattern; that is
  inferred and has no web scene.
- **WebGL2 on Windows startup cost**: lit shaders link in 6.3–11.0 s, and
  fx-showcase's cold start is 25.8 s in Chrome and 26.7 s in Edge (WebGPU
  0.6–0.7 s). Parallel shader compile and a lighter GL lit shader are owed.
- **Firefox**: not installed on studio-win; never run.
- **Safari**: web-reference drives Chrome only.
- **`og check` on Windows without tsrs**: a truncated bunx TypeScript install
  gives an unreadable tsgo panic. `og check` could detect this and say which
  directory to clear.
