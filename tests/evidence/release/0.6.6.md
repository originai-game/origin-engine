# Release 0.6.6 (2026-10-28 UTC)

All five npm packages are published at 0.6.6, and `latest` points to 0.6.6.
Tag `v0.6.6` is pushed at `71b2f032a6e74509e670acc5eabe5dd462b19cf5`, the
commit `release.yml` run 40620857254 checked out.

This is a patch release (docs/release.md §3) with the simulation
**unchanged** and no IDL member changed. No crate changed since 0.6.5:
it is a knowledge release. `changelog.json` records no breaking entries,
no fixed lines and two added lines:

- **Six craft skills move into the knowledge package** (`9c93992e`), from
  origin-agent main `4e666675` (`knowledge/game/skills/`), under the names
  games already pin: `architecture-discipline`, `component-forge`,
  `level-texturing` (with `scripts/texture-level.ts`), `localization`,
  `recipe-craft` and `visual-acceptance`. They name no platform tool or
  service, have numbered sections and point to the og-* skills and the
  wiki for every API; `localization` is the craft beside og-i18n's API.
  texture-level.ts's providers are `handoff` (the default), `http` (an
  OpenAI-compatible image endpoint, `--endpoint` or `OG_IMAGE_ENDPOINT`,
  `OG_IMAGE_API_KEY`) and `dashscope`; runs whose settings say `agent` or
  `gateway` resume under the new names. The validator now resolves a
  section reference to any skill it ships (`recipe-craft §2`, and
  `og-i18n §6`, which it used to read as the citing skill's own).
- **`payload` and `defaultRoots` are public contract** (`392a0979`):
  `knowledge/scripts/lib.ts`'s `payload(roots)` and `defaultRoots(pkg?)`,
  with the `PayloadFile` and `Roots` shapes, sit beside `installed`,
  `mount` and `summary` in AGENTS.md. origin-agent reads the knowledge
  straight from the installed package with `payload(installed(dir).roots)`.
  Nothing about them changed.
