# Release 0.7.4 (2026-10-30 UTC)

All five npm packages are published at 0.7.4, and `latest` points to 0.7.4.
Tag `v0.7.4` (annotated) is pushed at
`92c53a9a9b01c992e5b924dcf6375db3750130e4`, the commit `release.yml` run
40990482032 checked out.

This is a patch (docs/release.md §3) with the simulation **unchanged** and
no IDL member changed. The change since 0.7.3 is shared frames:

- `67ba0132` og-render `shared_frames`: a renderer's frames shown in another
  process's window through shared GPU memory (IOSurfaces by Mach rendezvous
  on macOS, Vulkan opaque fds on Linux, D3D12 NT handles on Windows), on
  Origin Desktop's `shared-frame` wire.
- `b562fe7a` og-host-node: with `ORIGIN_FRAMES_SOCKET` set (Origin Runner
  sets it when Origin Desktop draws the Session's engine), `og run` and
  `og dev` present each loop frame in that window and render at the size it
  asks for. Without the variable nothing changes.

`changelog.json` records 0.7.4 as `kind: patch`, simulation `unchanged`, no
breaking entries, one added line and no fixed lines.
