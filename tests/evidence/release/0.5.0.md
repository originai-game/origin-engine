## Publication and registry verification

`scripts/release.sh publish` published all three platform packages first,
then engine and create-game, using the injected token without exposing it.
`git push origin v0.5.0` succeeded.

`scripts/release.sh verify --registry` passed in 114.3 s overall:
darwin-arm64 Metal 63.3 s and linux-x64 container 45.9 s. Two initial
attempts could not resolve create-game 0.5.0 while npm metadata propagated.
After the version became visible, a fresh Bun cache passed; no packages
were rebuilt or republished. Registry integrity independently matches
all five tarballs.

Local receipts and logs: `.amp/in/release-0.5.0/` (functional, Rumpus,
pack, verify, publish, registry attempts, integrity, wasm sizes and the
downloaded Windows receipt). Windows logs remain in its workspace under
`.amp/in/engine-0.5.0-win/`. The release manifest includes all five hashes
and the exact Windows consumer receipt alongside Mac/Linux verification.

This release run did not retry the blocked iPhone Safari automation row
or run InstaBox acceptance; those remain separate checks.
