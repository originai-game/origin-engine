# Release 0.6.5 (2026-10-27 UTC)

All five npm packages are published at 0.6.5, and `latest` points to 0.6.5.
Tag `v0.6.5` is pushed at `76859981cc5d0e3112378d133fb8358d15d7fb58`, the
commit `release.yml` run 40572705572 checked out.

This is a patch release (docs/release.md §3) with the simulation
**unchanged**. `changelog.json` records no breaking entries and four fixed
lines:

- **og check on a truncated TypeScript install** (`og-check-broken-tsgo`,
  `a9e0b1ac`). Where tsrs has no package, og check runs tsgo through `bun x`.
  An interrupted install used to give a Go panic, or `Cannot find global
  type` errors that read as the game's. og check now verifies the install
  before tsgo runs and reads tsgo's panic. It names the incomplete
  directory and the fix: delete it, or `bun pm cache rm`, then rerun.
  `og doctor` reports the install as broken.
- **The knowledge mount after the agent-repo split** (`post-migration-refs`,
  `0ca55b4d`). `scripts/mount.ts` mounts into an origin-agent checkout's
  `knowledge/`. `installed`, `mount` and `summary` are unchanged; their
  signatures are a public contract (AGENTS.md). AGENTS.md's probe contract
  path now points to origin-agent.
- **og-ui glass and a view's glow chain on Windows WebGL2**
  (`webgl2-level-size`, `0f148b3e`). ANGLE on D3D11 answers
  `textureDimensions` of a view with base mip level b with level 2b's size,
  so the glass blur was about twice as wide. Each level now takes the size
  it reads from a uniform. Every other level-view read was audited and is
  unaffected. Native frames are byte-identical.
- **WebGL2 cold start on Windows** (`webgl2-cold-start`, `893d9ea1`, and the
  trade-off note `e7d59916`). Programs link in the background with
  `KHR_parallel_shader_compile` (the vendored wgpu-hal GLES backend, ORIGIN.md
  patch 2). A GL-tier-only `AREA_LIGHTS` pipeline constant leaves the
  rect-light (LTC) code out of lit programs until a frame has an
  `og.RectLight`; metal, DX12 and WebGPU compile byte-identical WGSL. A scene
  that gets its first rect light during play pays the lit links again then
  (about 5 to 8 s on ANGLE D3D11); a rect light in the first scene, at
  intensity 0 if need be, moves them to load. `check.sh`'s wasm steps now
  count `third_party` as an input.

Test tooling, not shipped: `reference.ts` and `reference-gfx.ts` take
`--firefox` and drive Firefox through WebDriver BiDi (`firefox-bidi`,
`cfd87ba7`).

## Owed

- `packages/knowledge/scripts/sync-rules.ts` still reads one origingame
  checkout; its sources are now split between origingame and origin-agent.
  It is a manual tool no gate runs.
- WebGL2 on Windows: terrain, scatter copies, fluid3d and volumetric fog
  still link with the rect-light code; folding the two EFFECTS lit variants
  would remove one more lit program from the first frame. Firefox's WebGL2
  has no `KHR_parallel_shader_compile`, so its links stay serial.
- The Firefox adapter covers only `reference.ts` and `reference-gfx.ts`
  (not the screenshot, input and worker hooks of the other harnesses).
  Safari is out of scope.
