# Release 0.7.3 (2026-10-29 UTC)

All five npm packages are published at 0.7.3, and `latest` points to 0.7.3.
Tag `v0.7.3` (annotated) is pushed at
`77d7b7e7cf394d241fb5cba8a27aa43a613c4cad`, the commit `release.yml` run
40897324543 checked out.

This is a knowledge-only patch (docs/release.md §3) with the simulation
**unchanged**. No IDL member and no crate changed since 0.7.2. The one
change is `0ccf1ea3`:

- level-texturing's `texture-level.ts` paints with
  `gemini-nano-banana-2.1` by default. `qwen-image-2.1-pro` is still
  available with `--model`. The `http` provider sends Qwen's `seed` and
  `prompt_extend` only to Qwen models and sends the view's `size` to the
  others, as Gemini's route requires. `dashscope` refuses a model it does
  not serve. A resumed run keeps the model it started with.

`changelog.json` records 0.7.3 as `kind: patch`, simulation `unchanged`,
no breaking entries, no added lines and one fixed line.
