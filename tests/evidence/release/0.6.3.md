# Release 0.6.3 (2026-10-27 UTC)

All five npm packages are published at 0.6.3, and `latest` points to 0.6.3.
Tag `v0.6.3` is pushed at `b73124bdc47f72917e4d7b85e3b825c263d26f05`, the
commit `release.yml` run 40498415027 checked out.

This is a patch release (docs/release.md §3) with the simulation **changed**.
It fixes the cross-platform yaw drift that 0.6.2's replay gate found on
win32 (docs/release.md §4 F):

- og-nav's faceMovement turn is a yaw step through og-core's deterministic
  math instead of glam's `Quat::slerp`, which used the host's `sinf`.
- `og_core::math::quat_slerp` and `og_core::math::acos` are added, each
  pinned to the bit by a test. `og.terrain.sample`'s slope uses og-core's
  `acos`.
- The root `clippy.toml` has a `disallowed-methods` list. It refuses the
  host's libm transcendentals, glam's libm-backed rotations and glam's
  perspective constructors in the simulation crates. Render-only crates opt
  out in their own `clippy.toml`, and render-only code in a simulation crate
  takes a scoped `#[allow]` with a reason.
- `camera.worldToScreen` and `camera.screenToRay` can run inside a tick.
  Their perspective was already built with og-core's `sin_cos` (og-runtime's
  `view_proj`). `crates/og-runtime/tests/camera_projection.rs` now pins
  their bits.

The goldens are re-recorded. game-3d moves at ticks 61–65, and game-2d's
hashes are unchanged. `changelog.json` records 0.6.3 as a patch with
simulation `changed`, no breaking entries and three fixed lines.
