## Access boundary

The Windows development Agent Server is reachable through loopback-only
SSH forwarding. Real-thread acceptance cannot register a runner until
Identity accepts the platform development key for delegation. The owner
authorized the platform fix and its deployment, and clarified that the
development key is full-featured, not a runner-only exception. Ordinary
platform credentials must not gain that authority. No unrelated account
key is used to bypass this failure.
