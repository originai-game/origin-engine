# Release 0.3.0 (2026-10-23)

Prepared on the owner's Mac (`macrunner`, `/Volumes/app/origin-engine`)
from 52f739a7 (`release: 0.3.0` is d8bcf2d2; 52f739a7 adds the win32-x64
package to `release.sh publish`, outside the packaged inputs). The release
carries the depth wave (nine streams), its debt round and the UI styles
branch; CHANGELOG.md's 0.3.0 section lists the API changes, a minor bump
with renames (`og.load.skin` is `og.load.style`). 0.2.0 was already on the
registry (published 2026-10-22), so the owner chose 0.3.0 over 0.2.1 for
this state (2026-10-23). It is the first version that ships
`@origingame/engine-win32-x64` (F7).
