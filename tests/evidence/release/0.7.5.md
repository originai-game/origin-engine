# Release 0.7.5 (2026-10-31 UTC)

All five npm packages are published at 0.7.5. Tag `v0.7.5` (annotated) is
pushed at `188fdbff1b75c5d32c68873af49953a4534e71d1`, the commit
`release.yml` run 41149347869 checked out.

This is a patch (docs/release.md §3) with the simulation **unchanged** and
no IDL member added or removed (`AnchorDesc.margin`'s doc now says it insets
every edge). Games on a built-in UI style look different. The changes since
0.7.4:

- `bc65bed4` og-ui: a style's `fonts` block takes `cjk` and `cjkDisplay`,
  Simplified Chinese companions beside the role's Latin face. Every built-in
  style names one (templates/styles/cjk: Noto Sans SC, Noto Serif SC, ZCOOL
  KuaiLe, Fusion Pixel; OFL), cooked in only for a game with a `zh` string
  table. A style's `tone` is what a button's label ink is judged against
  (7:1). Centred labels in a column take its width. `og.ui:` warns about a
  control laid out past the screen with nothing to scroll to it. The neon
  style's glow marks the button and the title only, and its numbers are
  Chakra Petch SemiBold.
- `abd534b4` og-probe: the steps due after a script's `advance` wait until
  it has stepped and run at the tick it reaches.

`changelog.json` records 0.7.5 as `kind: patch`, simulation `unchanged`, no
breaking entries, three added lines and four fixed lines, from CHANGELOG.md's
section.
