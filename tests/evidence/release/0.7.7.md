# Release 0.7.7 (2026-10-31 UTC)

All five npm packages are published at 0.7.7. Tag `v0.7.7` (annotated) is
pushed at `94a9c8b24aff8793c0ae73dcc6eae2c67a79cd9a`, the commit
`release.yml` run 41174651541 checked out. The `ci` gate passed on it
(and on its parent `23427585`) before the publish.

This is a patch (docs/release.md §3) with the simulation **unchanged** (the
golden replays): IDL members added, off by default, none removed. The
changes since 0.7.6:

- `aa99a5bf` og-cook: the built-in look presets and style assets are
  statics, so `og` carries each CJK font once instead of twice.
- `3860ca2f` knowledge: og-core and og-game say the cited `examples/*`
  games are in the GitHub repository, not the installed package.
- `f97529db` input: mouse-look. `og.PointerLock { wanted, locked }` and
  `og.Pointers.movement`; the web shell requests the pointer lock on the
  next press on the canvas while `wanted`, exits it when not, reports
  `pointerlockchange` back and holds the absolute position while locked.
  Injected pointer events, `og.PointerMove` and the command channel
  (`mouse_move`, `pointer_lock`) carry it; native runs never lock.
- `23427585` og-cook: `.mp3`, `.ogg` (Vorbis) and `.flac` sounds cook like
  a WAV (symphonia, cook feature only; never the runtime or the wasm).
- `5f60c31b` tests/install: step 8, an MP3 sound cooks and plays with the
  installed `og` (below).

`changelog.json` records 0.7.7 as `kind: patch`, simulation `unchanged`, no
breaking entries, two added and two fixed lines, from the `unreleased`
block the changes wrote.
