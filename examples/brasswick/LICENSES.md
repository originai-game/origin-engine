# Brasswick's asset licences

Every asset is generated by `tools/make-assets.ts` (deterministic: seeded,
no clock, no download) except the UI style, its art and fonts, which are
the engine's fantasy pack of October 2026 kept in the game.

| Files | Licence | Origin |
|---|---|---|
| `assets/tiles/*`, `assets/maps/*`, `assets/sprites/*`, `assets/fx/*` | CC0 1.0 | drawn by `tools/make-assets.ts` (the levels from `tools/levels.ts`) |
| `assets/audio/*.ogt` | CC0 1.0 | og cook's procedural sound presets (`og sfx`), written by `tools/make-assets.ts` |
| `assets/music/vault.wav` (not committed) | CC0 1.0 | synthesised by `tools/make-assets.ts` ("The Vault Turns") |
| `assets/strings/*.ogt`, `assets/looks/brasswick.ogt` | CC0 1.0 | written for this game |
| `assets/styles/brasswick/style.ogt` | CC0 1.0 | the engine's fantasy style pack's style file of October 2026, recoloured brass and soot |
| `assets/styles/brasswick/atlas.png`, `icons.png` | CC0 1.0 | `templates/styles/fantasy` of October 2026 (its `LICENSES.md`, beside them) |
| `assets/styles/brasswick/Cinzel-Bold.ttf`, `Newsreader-Medium.ttf` | SIL Open Font License 1.1 (`assets/styles/brasswick/OFL.txt`) | `templates/styles/fantasy` |
