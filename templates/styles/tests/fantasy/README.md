# fantasy: review frames

These are the captures for the art review (docs/ui.md §6.3). They are
recorded on macrunner with Metal by `og ui sheet`. The core sheet's 100 %
cells are also references that `packages/engine/extensions/tests/ui-pack-sheets.test.ts`
reads (`templates/styles/references/fantasy`); the rest become baselines
when the reviewer accepts them.

| File | What it shows |
| --- | --- |
| `sheet-fantasy-<desktopHd|phonePortrait>-<100|150>.png` | The core-control state sheet (`og ui sheet fantasy`): its controls, fields, surfaces and overlays pages, every control at rest and in its hover, pressed, focus-visible, selected, disabled and selected-and-disabled states |
| `rpg-inventory-desktop-100.png` | rpg/fantasy normal page (bag and equipment), desktop at 100 % |
| `rpg-inventory-phone-100.png` | rpg/fantasy normal page, phone at 390×844 and 100 % |
| `rpg-journal-desktop-150.png` | rpg/fantasy stress page (party, turn order, map, conversation, journal, tracker and compass), desktop at 150 % |
| `rpg-journal-phone-150.png` | rpg/fantasy stress page, phone at 390×844 and 150 % |

Desktop cells are 1920×1080 and phone cells 390×844 (docs/ui.md §6.2).
Commercial review references: Baldur's Gate 3 and Diablo IV (§4).
