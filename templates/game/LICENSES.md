# Template asset licences

Every binary the template ships, with its licence; `@origingame/create-game`
carries this file into each scaffolded project.

| File | Licence | Origin |
|---|---|---|
| `assets/models/dropship.glb` | MIT (copyright 2026 Leichtbier) | the `core-business` example of OriginGame's `origingame-examples` repository (`examples/core-business/assets/dropship.glb`, generated by its `dropship.py`); its `LICENSE` is MIT. Also a test model of the engine (`crates/og-tests/assets/`) |
| `assets/models/walker.glb` | CC0 1.0 | self-made by the Origin Engine authors: a 13-node skinned walker of boxes with two morph targets and six clips (LINEAR, STEP, CUBICSPLINE, weights; footstep markers in `extras."og.events"`), generated by `crates/og-anim/tools/make_rig.py` (deterministic). The scene's `trickster` and the guard are both instances of it |
| `assets/textures/stone.png`, `assets/textures/stone_n.png` | CC0 1.0 | self-made by the Origin Engine authors: procedural value-noise tiles and the normal map of the same height field, generated by `templates/tools/make-template-assets.py` |
| `assets/audio/blip.wav` | CC0 1.0 | self-made: a 0.5 s rising sine pickup sound, same script |
| `assets/audio/click.ogt` | CC0 1.0 | og-cook's `click` sound preset (`og sfx click`), synthesised at cook time |
| `assets/fonts/NotoSansSC-Regular-subset.ttf` | SIL Open Font License 1.1 (`assets/fonts/OFL.txt`) | the OriginGame platform's project-template font: Noto Sans SC Regular subset to Latin, punctuation, kana, full-width forms and GB2312 by the platform's `engine/scripts/subset-font.py` |

## Provenance note

Until 2026-10-22 the `trickster` entity was `trickster.glb`, a model copied
from the `edg-king-match` example of `origingame-examples`, which declares
no licence (that repository grants none for the collection); the public
template ships nothing whose licence is not named (docs/release.md §4 R6),
so the entity is the walker now. The engine's own test copy stays in
`crates/og-tests/assets/` and in `templates/fx-showcase`, which no package
ships.
