# effekseer-starter

A curated starter set of Effekseer sample effects, bundled with the engine:
`og vfx add effekseer-starter` installs it into `assets/vfx/effekseer-starter/`.
Each effect comes from one contributor's sample zip at
https://effekseer.github.io/en/contributes/<contributor>/index.html (the
Effekseer sample effects, CC0 1.0). Credit: "Effekseer and <contributor>".
The full per-contributor packs (`effekseer-<contributor>`) download with
`og vfx add effekseer-<contributor>`.

Converted by `og vfx import` into the engine's own `type vfx` effects,
emitters and effect materials; spawn one as `vfx/effekseer-starter/<Effect>.ogt`.
Textures in `textures/` are copied from the samples (PNGs losslessly
recompressed, pixels unchanged); what did not convert is listed as
`# effekseer:` comments at the end of each effect's .ogt. Each file's
source in its contributor's zip is in `assets.json`.
