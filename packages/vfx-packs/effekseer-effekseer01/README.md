# effekseer-effekseer01

15 Effekseer sample effects by **Effekseer01**. Source: https://effekseer.github.io/en/contributes/Effekseer01/index.html
(the Effekseer sample effects, CC0 1.0). Credit: "Effekseer and Effekseer01". Install with
`og vfx add effekseer-effekseer01`; they land in `assets/vfx/effekseer-effekseer01/`.

Converted by `og vfx import` into the engine's own `type vfx` effects,
emitters and effect materials; spawn one as `vfx/effekseer-effekseer01/<Effect>.ogt`.
Textures in `textures/` are copied from the samples (PNGs losslessly
recompressed, pixels unchanged); what did not convert is listed as
`# effekseer:` comments at the end of each effect's .ogt. Each file's
source in its contributor's zip is in `assets.json`.
