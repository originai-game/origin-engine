# effekseer-pierre02

12 Effekseer sample effects by **Pierre02**. Source: https://effekseer.github.io/en/contributes/Pierre02/index.html
(the Effekseer sample effects, CC0 1.0). Credit: "Effekseer and Pierre02". Install with
`og vfx add effekseer-pierre02`; they land in `assets/vfx/effekseer-pierre02/`.

Converted by `og vfx import` into the engine's own `type vfx` effects,
emitters and effect materials; spawn one as `vfx/effekseer-pierre02/<Effect>.ogt`.
Textures in `textures/` are copied from the samples (PNGs losslessly
recompressed, pixels unchanged); what did not convert is listed as
`# effekseer:` comments at the end of each effect's .ogt. Each file's
source in its contributor's zip is in `assets.json`.
