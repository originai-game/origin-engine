# effekseer-andrewfm01

15 Effekseer sample effects by **AndrewFM01**. Source: https://effekseer.github.io/en/contributes/AndrewFM01/index.html
(the Effekseer sample effects, CC0 1.0). Credit: "Effekseer and AndrewFM01". Install with
`og vfx add effekseer-andrewfm01`; they land in `assets/vfx/effekseer-andrewfm01/`.

Converted by `og vfx import` into the engine's own `type vfx` effects,
emitters and effect materials; spawn one as `vfx/effekseer-andrewfm01/<Effect>.ogt`.
Textures in `textures/` are copied from the samples (PNGs losslessly
recompressed, pixels unchanged); what did not convert is listed as
`# effekseer:` comments at the end of each effect's .ogt. Each file's
source in its contributor's zip is in `assets.json`.
